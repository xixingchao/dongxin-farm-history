# 地方志文库工作站升级计划

## 当前基线

- 项目：东辛农场志
- 稳定成品包：东辛农场志_交付包_20260601_001759（本地归档，未随站点发布）
- 稳定压缩包：东辛农场志_交付包_20260601_001759.zip（本地归档，未随站点发布）
- 定位：v1 完整阅读交付版，包含最终阅读版 HTML、正文含表 PDF、结构化表格站、表格附录入口、源文件和 QA 报告。

## 最终目标

把当前单书交付包升级成两套成果：

1. GitHub 可发布的静态文库站。
2. 可复刻到其他书籍的地方志数字化工作站模板。

## GitHub 文库版目标

文库版不是替代当前成品包，而是在当前成品包上新增一个长期浏览入口。

建议站点结构：

```text
site/
  index.html                 # 文库首页
  books/
    dongxin/
      index.html             # 东辛农场志书页
      reader.html            # 当前最终阅读版
      pdf/                   # PDF 成品
      chapters/              # 分章/分节页面，后续可拆
      tables/                # 结构化表格详情
      reports/               # 质检与交付报告
      assets/                # CSS、图片、脚本
```

首轮 GitHub 版应完成：

- 首页：书名、简介、阅读入口、PDF 下载入口、表格入口、版本说明。
- 书页：22 章目录、122 个二级节链接、表格索引入口。
- 阅读页：沿用当前最终阅读版，不破坏已完成排版。
- 报告页：展示高优先级问题为 0 的自动质检摘要。
- GitHub Pages 兼容：所有链接使用相对路径，不依赖本机 E 盘绝对路径。

## 工作站模板目标

工作站模式要把本次流程抽象成可复刻流水线。以后换一本书，只替换输入资料和配置，不重新摸索全流程。

建议标准目录：

```text
book-workstation/
  config/
    book.yml                 # 书名、作者/单位、页码偏移、章节范围
    tables.yml               # 表格清单与跨页范围
  input/
    scans/                   # 原始扫描页
    ocr/                     # OCR 初稿
  workbench/
    body_chapters/           # 分章正文
    table_entries/           # 表格录入与固化数据
    qa/                      # 自动质检中间结果
  scripts/
    assemble_body.ps1
    build_reader.ps1
    build_tables.py
    audit_reader.ps1
    build_package.ps1
  output/
    site/
    package/
    reports/
  PROJECT_MEMORY.md
```

## 可复刻流程

1. 输入扫描图与 OCR 初稿。
2. 建立页锚：扫描页、原书页、章节、节。
3. 拆分正文：按章/节形成 Markdown。
4. 表格结构化：大表独立录入、跨页表用表号和页锚固定。
5. 正文组装：生成阅读版 HTML，清理页眉页脚和 OCR 工作痕迹。
6. 表格嵌入：将结构化表格插回正文，同时保留独立表格详情页。
7. 自动质检：目录链接、章节顺序、表格错位、跨页断段、调试词残留。
8. 交付打包：HTML、PDF、表格站、报告、源文件、版本说明。
9. 文库发布：生成 GitHub Pages 可用的相对路径静态站。

- 不覆盖 `成品归档` 中的 v1 稳定包。

- 所有新站点链接必须可脱离本机路径运行。
- 新增功能先静态化，后续再考虑搜索、全文索引、章节拆页。
